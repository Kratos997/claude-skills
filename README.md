# Claude Skills

Reusable skills, instructions, and configurations for Claude AI-assisted workflows.

## About

This repository is a collection of reusable skills for Claude. The contents are designed to support practical AI-assisted work across development, research, writing, and automation.

## Download the skills

Choose either method:

### Download a ZIP archive

1. Open this repository on GitHub: <https://github.com/Kratos997/claude-skills>.
2. Select **Code** and then **Download ZIP**.
3. Extract the downloaded archive. Each skill should remain in its own folder, containing its `SKILL.md` file and any supporting files.

### Clone with Git

```bash
git clone https://github.com/Kratos997/claude-skills.git
```

## Import skills into Claude Desktop

1. Open the Claude Desktop app.
2. Open **Settings** and go to **Capabilities** > **Skills**.
3. Choose **Upload skill** (or **Add skill**, depending on the version of Claude Desktop you use).
4. Select the folder for the skill you want to install, or compress that individual skill folder into a ZIP archive and select the ZIP file if the app asks for an archive.
5. Confirm the import, then enable the skill if Claude Desktop presents an enable/disable option.
6. Repeat the process for each skill you want to use.

After importing, start a new conversation or restart Claude Desktop if the skill does not appear immediately. Availability of Skills can depend on your Claude plan and the version of Claude Desktop installed; update the app and check Anthropic documentation if the menu names differ.

> Do not upload the entire repository as one skill unless it is structured as a single valid skill. Import each skill folder separately so Claude can identify its `SKILL.md` entry point.
